## 从 v2.3 到 v3.0.0，都变了什么

跨度有点大，挑重点说：

### 1. 通话功能下架

之前的**实时通话**功能这次下架了——实测延迟体验不达标。
等以后有**便宜又好用的双工模型**再恢复。

### 2. 本地语音模型：这次也没有

之前说过的**本地语音模型**（不联网、不要 Key 那种）同理——
方案体验没达到预期，先不做。现在的云端方案又便宜音色又稳，
等以后有更成熟的本地方案再考虑。

### 3. 一个角色只保留一个会话

- 每个角色只保留**一个会话**——就是你正在聊的那个，升级后接着聊，上下文都在
- 老用户如果有好几个会话：多出来的**不会消失**，会自动保存到你电脑的
  `C://Users//你的用户名//AppData//Roaming//com.amadeus.kurisu//sessions//`
  文件夹里（以 discarded_ 开头的文件就是它们）
- **强烈建议**：升级前把想留底的会话在旧版里先「导出 TXT」备份好

### 4. 可以发文档了

- 输入框左下角的按钮从图片图标换成了**回形针**
- 现在能发：**图片 + txt / md 文本文件**（AI 直接读内容）
- Word、PDF 这类复杂格式**不收**；单文件上限 200KB / 8 万字符
  （防止把上下文挤满）

### 5. 运行日志面板

设置 → 「运行日志」：后台在干什么实时滚动。
遇到问题点「复制报错」，把内容一起发到群里。

### 6. 界面大改版

- 系统标题栏去掉了，换成自绘的**金属边框**：按住顶部拖动窗口，
  「—」最小化到任务栏，托盘图标**单击一下就弹回**
- 点 ✕ 会弹个小窗让你选：**最小化**（收进托盘）还是**退出**——不会再一点叉就"人间蒸发"
- 各种多余的悬停提示、设置项都清理过了

### 7. 聊天模型更新

- 小米 mimo 升级到 v2.6-pro（v2.5 已下线，配置会自动迁移）
- DeepSeek 换成 V4.1-Flash（支持图片识别）

## 升级方法（重要：不要卸载旧版！）

**直接覆盖安装，不要卸载。**

双击 `Amadeus_3.0.0_x64-setup.exe`，安装到原目录即可。安装后聊天记录自动保留；
语音因为换了方案，需要按下方「语音配置三步走」重新填一次百炼 Key。

* * *

## 语音配置三步走（想让她说话的看这里）

1. 注册**阿里云百炼**账号，拿到 API Key
2. Amadeus → 设置 → 语音合成 → 粘贴 API Key
3. 点「一键复刻三个角色」→ 等约 10 秒 → 打开「启用」开关

复刻完全免费，只有之后每句合成按字符计费（0.8 元 / 万字符）。

* * *

## 保存聊天记录的方法（求稳的看这里）

1. 按 `Win + R`，输入以下路径并回车：

   ```
   %LOCALAPPDATA%\com.amadeus.kurisu
   ```

2. 找到 `EBWebView` 文件夹，整个复制到桌面备份
3. 安装新版
4. 如果聊天记录丢了，把备份的 `EBWebView` 复制回去覆盖

## 常见问题

**Q: 升级后聊天记录还在吗？**
A: 在。覆盖安装就行，不要卸载旧版。多出来的旧会话建议升级前先在旧版里导出 TXT 备份好。

**Q: 她怎么不说话？**
A: 三步：填百炼 Key → 一键复刻 → 打开「启用」。还不行就 设置 → 运行日志 看报错。

**Q: 语音有延迟 / 要花钱吗？**
A: 云端合成每句几百毫秒，日常聊天感觉不到。费用 0.8 元 / 万字符，重度使用一个月也就几块钱。

**Q: 通话功能呢？说好的呢？**
A: 延迟不达标，先不做了。等有便宜好用的双工模型再恢复，不是鸽，是它真的还不行。

**Q: 本地语音模型呢？**
A: 同理，体验没达标没做，等以后有更成熟的方案。

**Q: 发 txt 说不支持 / 发不了？**
A: 只收 txt / md 和图片，Word、PDF 不收。文件别超过 200KB。

**Q: 安装时弹蓝色警告 / 装完打不开？**
A: 多半是 Windows 拦截了未签名程序：弹提示时点「更多信息 → 仍要运行」；
装完打不开就把 Amadeus 的安装文件夹加入 Defender 白名单。

**Q: 遇到 bug 怎么反馈？**
A: 群里直接说 + 设置 → 运行日志 → 「复制报错」一起贴出来。
这是先行测试版，你们报的每个问题都会进正式版。
