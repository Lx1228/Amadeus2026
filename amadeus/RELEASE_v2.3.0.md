# Amadeus v2.3.0 更新说明

## 更新内容

### 1. 新增图片发送功能

现在可以在聊天中发送图片了！支持截图、照片等任意图片。

- 点输入框左下角的**图片按钮**，选择文件发送
- 或者直接 **Ctrl + V** 粘贴截图（微信截图、QQ截图后直接粘贴）
- 图片会自动压缩到 1024×1024，减少 AI 处理时间
- 支持多模态模型（mimo-v2.5、GPT-4o 等），AI 可以"看懂"你发的图片

**使用方法：**
1. 点输入框左下角的图片图标 → 选择图片文件
2. 或者截图后直接 Ctrl + V 粘贴
3. 图片预览会显示在输入框上方，点 ✕ 可以取消
4. 点发送，AI 会根据图片内容回复

### 2. 导出聊天记录改进

导出聊天记录时现在会弹出**保存对话框**，可以自己选择保存位置（桌面、其他盘、自定义文件夹），不用再去"下载"目录找了。

- 会话管理 → 点「导出 TXT」→ 选择保存位置
- 文件名自动带会话名和时间戳

### 3. 其他优化

- 升级 WebView2 缓存管理，提升启动稳定性
- 版本号升级到 v2.3.0

## 升级方法（重要：不要卸载旧版！）

**直接覆盖安装，不要卸载。** 卸载会删除聊天记录和配置。

双击 `Amadeus_2.3.0_x64-setup.exe`，安装到原目录即可。安装完成后，原有的聊天记录、API Key、克隆音色都会保留。

* * *

## ⚠️ 安装前必须做这一步（重要！）

Windows Defender 会把未签名的 app.exe 误判为病毒并拦截，导致**安装后打不开**。安装前必须加白名单：

1. 双击 `add-defender-exclusion.bat`
2. 弹出 UAC 窗口点「是」
3. 看到 OK 绿色提示就完成了

这会给 Amadeus 目录和 app.exe 加 Defender 排除项，之后不会再被杀。

* * *

## 图片发送注意事项

- **模型要求：** 需要支持多模态的模型才能识别图片内容（mimo-v2.5、GPT-4o 等）。如果用不支持图片的模型，会报错。
- **发送速度：** 发送图片后，AI 回复会比纯文字慢 1-3 秒（需要先"看懂"图片再回复）。
- **图片压缩：** 图片会自动压缩到 1024×1024，大图会缩小，但不影响 AI 理解。
- **历史图片：** 聊天记录里的图片以 data URL 形式保存在 localStorage 中。如果图片很多，可能会占用较多存储空间。

* * *

## 保存聊天记录的方法

如果你担心升级出问题，可以备份聊天记录：

1. 按 `Win + R`，输入以下路径并回车：
   
   ```
   %LOCALAPPDATA%\com.amadeus.kurisu
   ```
2. 找到 `EBWebView` 文件夹，整个复制到桌面备份
3. 安装新版
4. 如果聊天记录丢了，把备份的 `EBWebView` 复制回去覆盖

## 常见问题

**Q: 升级后聊天记录还在吗？**  
A: 直接覆盖安装就在。不要卸载旧版。

**Q: 升级后 API Key 要重新填吗？**  
A: 不用，覆盖安装会保留配置。

**Q: 图片发送报错 "No endpoints found that support image input"？**  
A: 你用的模型不支持图片输入。请切换到支持多模态的模型（如 mimo-v2.5）。

**Q: 图片发出去了但 AI 回复很慢？**  
A: 正常。AI 需要先"看懂"图片再回复，比纯文字慢 1-3 秒。

**Q: 安装后打不开/闪退？**  
A: 是 Windows Defender 拦截了。按上方「安装前必须做这一步」加白名单后重试。
